# Hospital Management System

A full-stack Hospital Management System built to streamline the management of patients, doctors, departments, and appointments.

## 🚀 Live Demo

🌐 **Frontend (Vercel):**
https://hospital-management-system-6h9x.vercel.app

🔗 **Backend API (Render):**
https://hospital-management-system-qa6u.onrender.com

## Features

- Patient Management
- Doctor Management
- Department Management
- Appointment Scheduling
- Dashboard with live statistics
- Today's appointments overview
- RESTful APIs
- Responsive frontend

## Tech Stack

### Backend
- Java
- Spring Boot
- Spring Data JPA
- PostgreSQL
- Maven

### Frontend
- HTML
- CSS
- JavaScript

## Project Structure

```
hospital-management-system/
│
├── backend/     # Spring Boot REST API
└── frontend/    # HTML, CSS, JavaScript
```

## Getting Started

### Backend

```bash
cd backend
mvn spring-boot:run
```

The backend runs on:

```
http://localhost:8080
```

### Frontend

Open `frontend/index.html` in your browser, or serve the frontend using a local web server.

## API Modules

- Patients
- Doctors
- Departments
- Appointments

Each module supports CRUD operations through REST APIs.
